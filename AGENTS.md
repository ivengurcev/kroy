# AGENTS.md

## Проект

Kroy — прототип мультисайтовой платформы на JavaScript, React 19, Yarn 4 PnP, esbuild и Vyaz. Редактор обслуживается приложением из `server.mjs`; страницы собираются из React-компонентов в `parts/`.

Метаданные полей редактора извлекаются из JSDoc скриптом `scripts/discoverParts.mjs`. Все артефакты создаются в `dist/` и не должны редактироваться вручную:

- `dist/public/` и `dist/ssr/` — сборки Vyaz;
- `dist/kroy/` — промежуточные файлы Kroy;
- `dist/sites/<site>/` — готовые статические сайты.

## Правила работы

- Вносить минимальные изменения строго в рамках задачи.
- Не добавлять новые абстракции и зависимости без явной необходимости.
- Не менять соседний код и форматирование попутно.
- Сохранять JavaScript; не переводить проект на TypeScript.
- Не заниматься сборкой сайтов и динамическими импортами без отдельного запроса.
- `id` элемента страницы является внутренним состоянием редактора; сохраняемый JSON страницы содержит только `{ part, props }`.
- Именовать директории в `kebab-case`, React-компоненты в `PascalCase`, обычные JS-модули в `camelCase`.
- Использовать для запчастей только идентификаторы `@kroy/` с сегментами в `kebab-case`.

## Проверка

Пока проект разрабатывается без тестов: не добавлять тесты, тестовые фреймворки и тестовые команды, если пользователь явно не попросил об этом. Для проверки изменений использовать подходящую существующую сборку или команду и `git diff --check`.
