# AGENTS.md

## Проект

Kroy — ранний прототип мультисайтовой платформы на JavaScript, React 19, Yarn 4 PnP и esbuild. Страницы собираются из React-компонентов — запчастей из `parts/`.

Метаданные полей редактора извлекаются из JSDoc компонентов скриптом `scripts/discoverParts.mjs`. Файлы в `generated/` создаются автоматически и не должны редактироваться вручную.

## Правила работы

- Вносить минимальные изменения строго в рамках задачи.
- Не добавлять новые абстракции и зависимости без явной необходимости.
- Не менять соседний код и форматирование попутно.
- Сохранять JavaScript; не переводить проект на TypeScript.
- Не заниматься сборкой сайтов и динамическими импортами без отдельного запроса.
- `id` элемента страницы является внутренним состоянием редактора; сохраняемый JSON страницы содержит только `{ part, props }`.

## Проверка

Пока проект разрабатывается без тестов: не добавлять тесты, тестовые фреймворки и тестовые команды, если пользователь явно не попросил об этом. Для проверки изменений использовать подходящую существующую сборку или команду и `git diff --check`.
