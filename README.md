# Kroy

**Kroy** — мультисайтовая платформа для сборки и управления небольшими сайтами из переиспользуемых React-компонентов. Создаётся как рабочий инструмент для разработки и обслуживания клиентских сайтов.

Основа платформы — [Vyaz](https://github.com/ivengurcev/vyaz).

> **Статус:** ранний прототип. Ниже отдельно описаны текущая структура и запланированная архитектура; перечисленные возможности платформы пока не следует считать реализованными.

## Идея

Сайт собирается из готовых **запчастей** (*parts*). Каждая запчасть — обычный React-компонент, который можно использовать в составе страницы. Запчасть может быть оформлена как отдельный приватный пакет Yarn Workspace.

Редактируемые свойства запчасти предполагается описывать в пользовательском поле её `package.json`. На основе этого описания Kroy сможет формировать поля редактора и проверять введённые значения. Контракт ещё предстоит проверить на практике.

## Текущая структура

```text
kroy/
├── layout/
│   └── Section.jsx
├── parts/
│   ├── contacts/
│   │   ├── Contacts.jsx
│   │   └── package.json
│   └── hero/
│       ├── Hero.jsx
│       └── package.json
├── package.json
└── yarn.lock
```

Проект использует **JavaScript, React и Yarn 4 с Plug'n'Play (PnP)**. TypeScript не требуется.

## Планируемая архитектура

- **Мультисайтовость:** одна платформа обслуживает множество независимых сайтов.
- **Хранение:** PostgreSQL; структура страницы, порядок запчастей и их свойства хранятся вместе в документе JSONB.
- **Редактор:** интерфейс формируется из метаданных запчастей; владелец сайта сможет менять тексты и изображения, а администратор платформы — управлять структурой и оформлением.
- **Публикация:** сохранение изменений приводит к обновлению опубликованного сайта, без отдельного этапа черновиков в MVP.
- **Публичные страницы:** преимущественно статические файлы, обслуживаемые Nginx.
- **Динамические функции:** запросы `/api/*` проксируются Nginx на общий backend (Hono); сайт определяется по исходному домену.
- **Отзывы:** отправка посетителями и модерация владельцем сайта.

## Разработка

Установить зависимости:

```bash
yarn install
```

Команды запуска и сборки будут документированы после появления работающего приложения.

## Вне MVP

В перспективе Kroy сможет экспортировать отдельный сайт в автономный дистрибутив: его данные, используемые запчасти, необходимые сервисы и инструкцию по развёртыванию. **Сейчас разрабатывается только мультисайтовая платформа**; отдельный режим работы для одного сайта не предусмотрен.
