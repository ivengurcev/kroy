# Kroy

Kroy — ранний прототип мультисайтовой платформы для сборки небольших сайтов из переиспользуемых React-компонентов — **запчастей** (*parts*).

## Как это устроено

Запчасти находятся в `parts/`. Генератор обнаруживает компоненты и читает JSDoc над их `export default`: обычные `@param` описывают свойства, а `@kroy` настраивает поля редактора.

```jsx
/**
 * @param {object} props
 * @param {string} props.phone - Телефон
 * @kroy phone widget=tel format=ru
 */
export default function Contacts({ phone }) {
    return <a href={`tel:${phone}`}>{phone}</a>;
}
```

На основе этих описаний Kroy создаёт:

- реестр React-компонентов для рендеринга страницы;
- JSON-метаданные для автоматического построения редактора.

Страница хранится как упорядоченный список запчастей и их свойств. Деморедактор позволяет добавлять, удалять и переставлять запчасти, менять данные и сразу видеть результат.

## Запуск прототипа

```bash
yarn install
yarn editor:demo
```

После сборки откройте `editor.html` через локальный HTTP-сервер.

Отдельно обновить сгенерированный каталог запчастей:

```bash
yarn parts:generate
```

Проект использует JavaScript, React 19, Yarn 4 с Plug'n'Play и esbuild.
