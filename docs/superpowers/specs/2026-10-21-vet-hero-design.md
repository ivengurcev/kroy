# Hero сайта Алёны Путинцевой

`@kroy/hero` переносит композицию `design/vet-hero/index.html` в самостоятельный
React-компонент и CSS Module. Общие значения берутся из `--site-*`, локальными
остаются композиция, пропорции, размеры Hero и градиенты.

Фотография задаётся неизменяемым URL из `photo` как CSS background. Социальные
ссылки рендерятся только при непустом URL и используют публичную SVG-разметку
из референса. Контент описывается JSDoc и редактируется существующими Field и
ImageField.

Корневой Hero является CSS-контейнером. Breakpoint’ы используют container
queries, поэтому мобильная композиция включается и в узком предпросмотре.
Глобально меняется только публичный `body { margin: 0 }` в `layout/site.css`.

Проверка ограничена `git diff --check` и `yarn vyaz:build`.
