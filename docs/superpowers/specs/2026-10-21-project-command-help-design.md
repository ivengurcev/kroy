# Справка по командам проекта

## Решение

Добавить статический скрипт `scripts/help.mjs`, который выводит на русском
языке существующие команды Kroy, сгруппированные по назначению, и короткие
рабочие сценарии. Скрипт только печатает текст и не запускает другие команды.

Yarn 4 резервирует прямой вызов `yarn help`, поэтому гарантированная команда
Kroy — `yarn kroy:help`. Для явного запуска одноимённого package script также
поддерживается `yarn run help`.

`README.md` кратко повторяет команды, их реальные аргументы и сценарии. Новые
зависимости, параметры и изменения поведения существующих команд не нужны.

## Проверка

Выполнить только `git diff --check` и `yarn vyaz:build`.
