# Каталог и компактные формы

## Цель

Сделать каталог удобным для создания товаров внутри категорий на десктопе и мобильных экранах, а короткие поля административных форм — компактными и единообразными.

## Решение

- Каталог сохраняет единое состояние `value/onChange`; мобильный режим меняет только отображение: дерево скрывается при выборе элемента, редактор занимает экран и возвращает пользователя кнопкой «Назад к каталогу».
- В строке категории появляется отдельная кнопка `+`, создающая локальный товар с этой категорией. Перемещение и удаление остаются в меню действий строки.
- Нормализация каталога перестаёт отбрасывать элементы с пустыми обязательными названиями: API возвращает понятную ошибку, а локальный черновик сохраняется.
- Существующий `FormField` и стили полей расширяются режимом `compact`; короткие поля получают строковую компоновку, длинные и сложные контролы остаются вертикальными.

## Ограничения

API, схема БД, формат страниц и публичные карточки товаров не меняются. Отдельная бизнес-логика для мобильных устройств не создаётся.

## Проверка

После реализации выполняются `git diff --check` и `yarn vyaz:build`; мобильный сценарий каталога проверяется вручную на 320/390 px.
