# Общие дизайн-токены публичного сайта

`styles/SiteTheme.module.css` содержит scoped-набор универсальных переменных
`--site-*` и базовое оформление публичного поддерева. `layout/SiteRoot.jsx`
применяет единственный theme-класс к нейтральной обёртке без геометрических
правил.

`SiteApp` оборачивает текущую страницу в `SiteRoot`. В редакторе `SiteRoot`
находится только внутри inert-обёртки публичного `Page`; административные
элементы остаются в `AdminTheme` и не наследуют публичное оформление.

Тема статична. Хранение значений по сайтам, переключение тем и переработка
существующих запчастей не входят в задачу.

Проверка ограничена `git diff --check` и `yarn vyaz:build`.
