# Загружаемые SVG

Новые SVG остаются векторными, но перед записью обязательно очищаются на сервере.
Ранее сохранённые файлы автоматически не изменяются. API загрузки, БД и растровая
обработка не меняются.

## Путь обработки

1. `server/media/processImage.mjs` определяет формат через Sharp.
2. SVG передаётся в `server/media/sanitizeSvg.mjs`: строгий XML-разбор в jsdom,
   проверка корня `svg`, затем DOMPurify с явными списками элементов и атрибутов.
   Исполнение JavaScript и загрузка ресурсов в jsdom не включены.
3. Удаляются неподдерживаемые элементы и атрибуты; URI разрешены только как
   локальные фрагменты. Несуществующие после очистки ссылки удаляются.
4. Результат сериализуется и повторно разбирается как SVG/XML; проверяются
   пространство имён и размер. Документ без графических элементов отклоняется.
5. `storeMedia` записывает только очищенные байты; исходная копия не сохраняется.

Ошибка обработки использует существующий ответ загрузки `400 Invalid image`.
Вход и результат SVG ограничены существующими 10 MiB; общий лимит загрузки
50 MiB и ограничения Sharp остаются без изменений.

## Поддерживаемые элементы

| Назначение | Элементы |
|---|---|
| Документ, группы, определения | `svg`, `g`, `defs`, `symbol`, `use`, `title`, `desc` |
| Геометрия | `path`, `rect`, `circle`, `ellipse`, `line`, `polyline`, `polygon` |
| Статический текст | `text`, `tspan` |
| Градиенты | `linearGradient`, `radialGradient`, `stop` |
| Маски и отсечение | `mask`, `clipPath` |

Сохраняются `viewBox`, размеры, координаты, контуры, трансформации, геометрия
градиентов/масок, `fill`, `stroke`, прозрачность, параметры штрихов и базовые
атрибуты текста. Полный список атрибутов — в `sanitizeSvg.mjs`.
Цвета допускают имена, hex и числовые `rgb()`/`rgba()`/`hsl()`/`hsla()`.

`href`/`xlink:href` разрешены только у `use` и градиентов, только в форме `#id`.
`fill`, `stroke`, `mask`, `clip-path` поддерживают `url(#id)` (также с кавычками).
Идентификаторы ограничены ASCII: первая буква или `_`, далее буквы, цифры,
`_`, `.`, `:`, `-`. DOMPurify может удалить идентификатор, совпадающий со свойством
DOM (например, `part`); оставшиеся ссылки на удалённый идентификатор также удаляются.

## Ограничения

- Принимается корректный UTF-8 XML с корнем SVG. Обычный экспорт без `xmlns`
  нормализуется в пространство имён SVG.
- Любой `DOCTYPE` запрещён, включая безвредный SVG 1.1 DTD. Пользовательские и
  внешние сущности не поддерживаются. Некорректный XML не «ремонтируется».
- `style`, CSS-блоки, CSS-классы, CSS-переменные, внешние шрифты и ресурсы,
  `image`, фильтры, маркеры, гиперссылки, HTML/`foreignObject`, скрипты,
  обработчики событий и анимация не поддерживаются.
- CSS-зависимый экспорт может изменить внешний вид. Для совместимости перед
  загрузкой следует преобразовать оформление в SVG presentation attributes,
  а сложный текст при необходимости — в контуры.
- Санитайзер не гарантирует визуальную непустоту/идентичность рисунка:
  невидимая геометрия и сложные зависимости могут не отображаться.
- Компоненты отображения не изменены: цветные SVG используются через `<img>`,
  монохромные — через CSS `mask-image`, без inline-вставки пользовательского XML.

Санитизация дополняет существующие CSP с `sandbox`, `nosniff` и серверную
проверку принадлежности медиа сайту, а не заменяет их. Эти заголовки сохраняются
для API, ресурсов релиза `/_kroy/releases/…` и SVG в `/assets/…`.

## Проверка

`bun test server/media/sanitizeSvg.test.mjs`

Тесты вызывают загрузку с подменённым DB-клиентом, но настоящими обработчиком
изображений и файловым хранилищем. Проверяются байты сохранённых файлов,
отсутствие исходной копии, вредоносные конструкции, некорректный XML, лимиты,
векторные возможности, заголовки API, изоляция сайта и растровая регрессия.
При установленном Nginx отдельный временный экземпляр проверяет HTTP-заголовки
и байты SVG по двум публичным маршрутам; действующие релизы не изменяются.

В браузере вручную проверить новые загрузки: иконки карточек и акцентного блока,
глобальную HR-иконку, монохромную маску и цветной `<img>`, включая SVG с
`viewBox`, несколькими контурами и градиентом. Повторить после публикации.
